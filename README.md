🎯 舒尔特小游戏 - 专注力训练

基于 HarmonyOS NEXT 开发的舒尔特方格专注力训练游戏，包含三种模式、多难度调节、历史记录等功能。

 📱 功能特性

   一、三种游戏模式
   1.基础模式：数字分布在网格中，按顺序点击。
   2.转盘模式：数字在旋转的同心转盘上。
   3.小球运动模式： 数字在彩色小球上随机运动。

   二、难度调节系统

- **数字数量**：25 / 30 / 35 / 40 / 50
- **颜色模式**：纯色 / 随机彩色
- **运动速度**：1-5 级（仅转盘/小球模式）

   三、其他功能

- ⏱ 计时系统：从第一个点击开始计时
- ❌ 错误惩罚：点错数字 +3 秒
- 🏅 最佳成绩：自动记录并展示
- 📊 历史记录：保存所有游戏记录


   四、🛠 技术栈

| 技术 | 说明 |
|------|------|
| 开发平台 | DevEco Studio 5.0+ |
| 开发语言 | ArkTS / ArkUI |
| 目标平台 | HarmonyOS NEXT |
| 数据存储 | Preferences |
| 图形渲染 | Canvas 2D |
